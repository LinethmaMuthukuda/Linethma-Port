<h2>Python Calculator</h2>



<p>I created a desktop calculator using Python and Tkinter. It can perform basic mathematical operations, including addition, subtraction, multiplication and division. It also contains clear and delete buttons, decimal input and brackets.</p>



<p>While testing the calculator, I checked different calculations and corrected problems with invalid input and error handling.</p>



<h2>Sri Lankan NIC Checker</h2>



<p>I created a Sri Lankan NIC checker using Python and Tkinter. The application accepts both old and new NIC formats and displays the NIC type, gender, birth year, date of birth and age.</p>



<p>This project helped me practise input validation, date calculations, conditional statements and graphical user interface development.</p>



<h2>Personal Portfolio Website</h2>



<p>I customised a personal portfolio website using Hugo and the PaperMod theme. The portfolio presents information about me, my practical projects, skills and GitHub work.</p>



<p>I used Git and GitHub to manage the project and GitHub Actions to publish it through GitHub Pages. I also investigated and corrected a deployment problem caused by an incompatible Hugo version.</p>
